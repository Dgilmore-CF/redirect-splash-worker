Reference: Legacy Page (before redirect splash worker is in place)

What users used to see

This file is a reference-only mock. It represents what users might have seen before the redirect splash worker was deployed — for example, a direct hit on the old portal application, an origin 404, or a DNS-only A record.

Once the redirect splash worker is bound to a hostname like hr.dtg-lab.net, this kind of page is replaced by the professional splash. Open simulation/new/hcmx-hrprd.html to preview where users are eventually redirected.

For end-to-end testing in the lab, deploy the splash worker and the simulation worker as described in simulation/README.md, then visit https://hr.dtg-lab.net/.
